hyperbolic_cylinder

This folder regenerates the static hyperbolic-cylinder panel for Figure 3-8 from the case script, not from a plotting-only CSV.

Run all methods from this folder:

python hyperbolic_cylinder_all_methods.py

This writes hyperbolic_cylinder_all_methods_result.csv, hyperbolic_cylinder_all_methods_result.txt, hyperbolic_cylinder.png, and method-specific result files under the method folders.
