parabolic_cylinder

This folder regenerates the static parabolic-cylinder panel for Figure 3-8 from the case script, not from a plotting-only CSV.

Run all methods from this folder:

python parabolic_cylinder_all_methods.py

This writes parabolic_cylinder_all_methods_result.csv, parabolic_cylinder_all_methods_result.txt, parabolic_cylinder.png, and method-specific result files under the method folders.
