# 00 — INDEX: Entry Point to the docs_temp Knowledge Base
> Sources: all files in docs_temp/ (01–08, audit/*, debug_session/*, sources/*, code_map/*), cross-checked against repo code 2026-07-02 | Written: 2026-07-02 by understand-and-document workflow; updated 2026-07-03 (debug session recorded in 08)

**ddgclib** (v0.4.3 Alpha, `/home/endres/projects/ddgclib`) is an experimental **Lagrangian CFD library built on discrete differential geometry**: the mesh IS the fluid — each primal vertex of a `hyperct.Complex` is a material parcel carrying velocity `v.u`, volume-averaged pressure `v.p`, and fixed mass `v.m`; forces are the integrated Cauchy stress over barycentric dual cells, $F_i = \sum_j [-\tfrac12(p_i{+}p_j)A_{ij} + \tfrac{\mu}{|d_{ij}|}\Delta u\,(\hat d\cdot A_{ij})] + F_{\gamma,i}$, with no continuity equation (mass conserved by construction, pressure via weakly-compressible EOS on $\rho_i=m_i/\mathrm{Vol}_i$). The mesh backend is the external **hyperct** package symlinked at `./hyperct` (→ `/home/endres/projects/bilevel_param/hyperct` → `/home/endres/projects/hyperct/hyperct`). Project state in one line: the **static/equilibrium discretisation is machine-precision-validated (~1e-13)**, but **every dynamic case is unstable or imperfect** — the central open problem is retopology-induced EOS noise plus interface-curvature truncation, tracked as a ranked list in [06](06_known_issues_and_debug_history.md). This knowledge base supersedes the repo-root docs (CLAUDE.md test counts, ARCHITECTURE.md, four Fundamentals variants, FEATURES.md headings) for orientation — those contain verified-stale claims catalogued in 06 §5. Run everything with `/home/endres/anaconda3/envs/ddg/bin/python` from the repo root (base python lacks matplotlib and pytest).
