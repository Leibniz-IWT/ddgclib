## Which python / how to run
- Conda env **`ddg`**: `/home/endres/anaconda3/envs/ddg/bin/python` (numpy 1.26.3, ddgclib + hyperct importable, matplotlib available). Verified working.
- System `/usr/bin/python3` imports ddgclib but **lacks matplotlib** ("Plotting functions are unavailable" warning) → static plots/animations silently skipped. Use `ddg` env for cases.
- All case scripts do `sys.path.insert(0, <repo_root>)` themselves; run **from repo root** with the path style `python cases_dynamic/<case>/<script>.py`. Exception: `oscillating_droplet_p_ref` commands are written to be run **from inside that folder** (`python3 scripts/...`) — scripts there import sibling modules bare (`import pr33_operators`), which works because Python adds the script dir to `sys.path`.
- Common pipeline (all multiphase cases): `setup_*()` in `src/_setup.py` returns `(HC, bV, mps, bc_set, dudt_fn, retopo_fn, params)`; integrate with `symplectic_euler(HC, bV, dudt_fn, dt, n_steps, dim, bc_set, callback, retopologize_fn, remesh_mode=params['remesh_mode'], remesh_kwargs=params['remesh_kwargs'])`; record with `StateHistory(fields=['u','p','phase','is_interface'], save_dir=<case>/results/snapshots)`; animate with `dynamic_plot_fluid(..., phase_field='phase', interface_field='is_interface')`. Outputs always land in `<case>/fig/` and `<case>/results/`.
- Interface stress model (authoritative doc: `cases_dynamic/oscillating_droplet/INTERFACE_STRESS.md`): sharp interface = primal subcomplex; interface vertices carry `v.phase = -1` (`INTERFACE_PHASE`), per-phase arrays `v.m_phase/p_phase/rho_phase/dual_vol_phase`; force `F_i = Σ_j [-0.5(p_i+p_j)A_ij + (μ/|d_ij|)Δu (d̂·A_ij)] + F_st` with 2D `F_st = γ(t_next − t_prev)` (`ddgclib/operators/curvature_2d.py:surface_tension_force_2d`, exact for piecewise-linear interfaces) and 3D `F_st = −γ HNdA_i` (`ddgclib/_curvatures_heron.py:hndA_i_interface`). Young–Laplace init is a **mass pre-load** (`v.m_phase[1] = ρ_eq · vol`), NOT an additive pressure bump (doc explicitly corrects an earlier claim). Core operator: `ddgclib/operators/multiphase_stress.py:multiphase_stress_force`.

## oscillating_droplet/  (Rayleigh–Lamb validation, primary multiphase benchmark)
- **Run**: `python cases_dynamic/oscillating_droplet/oscillating_droplet_2D.py` (~2 min); `oscillating_droplet_3D.py` (~5 min); `mesh_convergence_2D.py`.
- **Physics** (`src/_params.py`): default = *overdamped* oil droplet in outer fluid: ρ_d=800, μ_d=0.5, ρ_o=1000, μ_o=0.1, γ=0.05 N/m, R0=0.01 m, ε=0.05 (mode l=2 ellipsoidal perturbation), L_domain=5·R0=0.05 m, refinement 3/3 (outer/droplet). Weakly-compressible EOS: c_s = max(10·u_scale, 1.0) = **1.0 m/s** → K_d = ρ_d·c_s² = 800 Pa, K_o = 1000 Pa (heavily softened). `UnderdampedParams` class (water 1 mm droplet in air, γ=0.072) exists but is not wired into the main scripts.
- **dt/n_steps** (computed at runtime, `oscillating_droplet_2D.py:79-91`): dt = min(0.25·dx_min/c_s, 0.5·√(ρ_d·dx_min³/γ)); t_end = min(t_end_2d, 5/β) ≈ 0.114 s; n_steps = t_end/dt + 1 ≈ **~460** at default refinement (dt ≈ 2.5e-4).
- **Success metric**: Rayleigh frequency ω²_2d = (l³−l)γ/(ρ_d R0³), Lamb damping β_2d = (2l²−1)μ_d/(ρ_d R0²); compare R_max(t) against `max_radius_envelope` (src/_analytical.py). `src/_metrics.py:oscillation_score` → `results/score.json`; `summary = max(l2_err, mass_drift, tail_growth−1)`. Baselines for regression comparison in `baselines/baseline_oscillation.json`, `baseline_equilibrium.json` (comparison fn returns `improved` bool).
- **Current state (results/score.json)**: `l2_error_normalized = 5.62`, `linf = 15.34`, `tail_growth = 1.68`, `mass_drift = 3.7e-16` — i.e. mass is conserved to machine precision but the trajectory is **far off analytical**; the case is currently a failing validation, not a passing one.
- **Outputs**: `fig/oscillating_droplet_2D_{fluid,phases,radius,energy,apex}.png`, `fig/oscillating_droplet_2D.mp4`, `results/snapshots/`, `results/score.json`.
- **Extra scripts**: `static_droplet_2D.py` (ε=0 equilibrium check, hardcoded **n_steps=100** — fastest debug loop); `oscillating_droplet_2D_adaptive.py` (Delaunay vs `remesh_mode='adaptive'` side-by-side; default smoke = **200 steps/mode, refine 2, ~20 s**; `--full` ≈ 80 min; `--n-steps`, `--refine` overrides); `oscillating_droplet_2D_mass_redist.py`; 10× `diagnose_*.py` forensic scripts (ls-verified 2026-07-02: a5_bisection, a5_dissect_2d, a5_step1_diff, balance, discrete_dp, dual_only, eos_ic, retopo_effect, split_methods, static).
- **Instability notes (verbatim)**:
  - `INVESTIGATION_PROMPT.md`: "`static_droplet_2D.py` (circular droplet, epsilon=0, full Delaunay retopo) **is unstable**: KE grows from ~0 to 4.4e-3 in 100 steps, the interface deforms even though epsilon=0 ... KE should remain at machine precision." vs "`Cube2droplet/diagnostic_no_retopo.py` ... **works correctly**: circularity 0.71 → 0.95 over 5000 steps". Suspects listed: YL pre-load imbalance, retopo destroying interface, surface-tension sign, phase-fraction error.
  - `src/_params.py:62-65`: "raising the [c_s] floor to 50 m/s cleans up acoustic reflections but tightens dt by ~10x — net effect on the oscillation score is weak once the **real KE-growth bugs (interface stress) dominate**. Revisit ... after Phase 6 (per-phase interface stress rewrite)."

## oscillating_droplet_p_ref/  (pressure-reference benchmark, tet-volume closure)
- Standalone benchmark folder (12-case study, 33 MB pptx `20260604_...twelve_cases.pptx`); outputs `out/` are gitignored. Benchmark-only operators live in `scripts/pr33_operators.py` (`VolumeGradientPressureState`, `Multiphase*` variants, `tet_volume_matrix`, `compressible_eos_pressure_correction`, `incompressible_volume_projection`, `active_retopology_tet_remap`...) — deliberately kept **out of** core `ddgclib/operators/stress.py` / `multiphase_stress.py`.
- **Run (from inside `cases_dynamic/oscillating_droplet_p_ref/`)**, canonical dev cases (README dev note: "**USE ONLY case 11 and 12 for dev purposes**"):
  ```bash
  python3 scripts/sphere_fheron_dynamic_integrator_p_ref.py --case-id 11 \
    --subdivision 1 --steps 81 --substeps-per-sample 5 --t-final 0.016 \
    --shape-mode-ar 1.05 --inertia-scale 1.08 \
    --out-dir out/dynamic_integrator_p_ref_case11_multiphase
  ```
  (`--case-id 12` = incompressible projection repeat; cases 5/6 use `--substeps-per-sample 20 --damping-ratio 0 --mass-model star-volume --mass-flux-coupling 1 --momentum-flux-coupling 1 --face-flux-mode lagrangian --density-change-limit 0`; also `scripts/sphere_fheron_flux_fv_ddgclib_benchmark.py --closure compressible|incompressible` for #5/#6.)
- **Physics**: l=2 perturbation (AR=1.05) of a sphere, R=1 mm, γ=0.072 N/m, ρ=1000; fit a2(t) vs Rayleigh–Lamb ω_l² = l(l−1)(l+2)γ/(ρR³); Heron surface force F_i = −γ(HN dA)_i; tet-volume continuity B_{t,i}=∂V_t/∂x_i with weak-compressible EOS correction or incompressible projection (equations in README lines 104-165).
- **Achieved**: final a2 = 0.02810 (#5/#6, 0 tet flips) and 0.02830 (#11/#12, ~1060–1084 changed tets, active Delaunay retopology in the solver path) vs Rayleigh 0.02989 at t=0.016 s — i.e. ~5–6% low.
- **Problem addressed** (verbatim): "after a Delaunay flip, the HC local dual cell around a vertex can change even when the physical liquid has not locally compressed ... the code can read a topological connectivity change as a physical compression/expansion event. That creates an artificial density/pressure jump and changes the droplet frequency." Workaround: pressure/continuity from **tet volumes** (rebuild B, tet masses, targets after every retopo). "This is a controlled benchmark closure, not a full conservative old-dual to new-dual overlap remap."
- 81 steps × 5 substeps at subdivision 1 → quick (minutes). GIF renderers: `scripts/render_dynamic_integrator_twophase.py --case-id 11 --source-dir out/...`.

## electrolysis_bubble/  (H2 bubble on electrode; gravity + gas injection)
- **Run**: `python cases_dynamic/electrolysis_bubble/electrolysis_bubble_2D.py`, `..._3D.py`; replay: `python cases_dynamic/electrolysis_bubble/view_polyscope.py --dim 2`. `electrolysis_bubble_fritz_2D.py` = **geometry-only smoke test** (solves axisymmetric Young–Laplace ODE γκ = P0 + ρ_diff g z for the Fritz sessile-bubble profile, builds two-phase mesh, plots; no time integration).
- **Physics** (`src/_params.py`): γ=0.072; ρ_liq=1000, μ_liq=0.1 (100× real water "for stability"); ρ_gas=10 (softened H2), μ_gas=0.01; **K_liq = K_gas = 1e5 Pa matched** — README calls this "the single biggest stability decision": physical K_gas<K_liq "collapses P = K(ρ/ρ₀−1) into negative territory and drives runaway inflation". g=9.81; R0=1 mm; L_domain=4 mm (half-side, box 8×8 mm); bubble nucleated at y = −0.5·(L−2R0); P0=0. Gas injection placeholder `src/_reaction.py:inject_gas_mass`, dm_dt_2d=2e-2 kg/(s·m), dm_dt_3d=2e-5 kg/s.
- **Numerics**: refinement outer/drop = 2/3 (2D), 1/1 (3D); dt = min(cfl_safety·dx_min/c_s, 0.4·√(ρ_liq dx_min³/γ)) with cfl_safety=0.05 (README quotes 0.025 for 3D but `_params.py` has a single `cfl_safety=0.05`; c_s = max(√(K/ρ)) = 100 m/s gas-side); t_end_2d=2e-4 s, t_end_3d=1.5e-4 s → n_steps ~O(5–10k) in 2D (dx~60 µm ⇒ dt~3e-8). Hydrostatic + Young–Laplace + gas-hydrostatic IC pre-load; **NaN sanitisation** required ("In 3D the barycentric dual construction produces NaN dual volumes at domain corners ... a single corner NaN poisons every subsequent Delaunay retopology"). Custom `WallClampBC` in `src/_setup.py`. Uses full `_retopologize_multiphase` — "Dual-only retopology ... was markedly less stable on this problem — the opposite of the observation in `static_droplet_2D`".
- **Success**: `src/_analytical.py` — capillary length λ=√(γ/(ρ_diff g))≈2.7 mm; Fritz detachment radius R_det=(3R0λ²/2)^{1/3}≈2.23 mm; expected 2D: R_eq climbs ~1.4–1.5 mm; 3D: 1→~1.9 mm; detachment heuristic = gas COM rises by 0.5·R0.
- **Known limitations (verbatim)**: "Delaunay retopology on a Lagrangian multiphase mesh does not preserve a thin detaching interface indefinitely; bubble mass is slowly lost once the interface starts to neck"; 3D off-centre builder "proved numerically fragile in the barycentric dual pipeline"; no contact-angle BC.
- **Outputs**: `fig/electrolysis_bubble_2D.mp4`, `_R.png`, `_z.png`; `results/snapshots/`.

## dam_break/  (gravity-driven collapse; smoke test for full pipeline)
- **Run**: `python cases_dynamic/dam_break/dam_break_2D.py` (multiphase water+air, uses `ddgclib.operators.multiphase_stress.multiphase_dudt_i` — the primary surface-tension operator test), `dam_break_2D_no_air.py` (single-phase, free surface via Tait–Murnaghan EOS toward P_atm, `boundary_filter` frees the surface), `dam_break_3D.py`, `dam_break_3D_no_air.py`.
- **Physics** (`src/_params.py`): Martin–Moyce geometry, a=0.05 m; tank L×H = 4a×2a = 0.2×0.1 m; column col_w×col_h = a×2a (2:1); 3D depth W=2a, col_d=a. Water ρ=1000/μ=1e-3; air ρ=1.225/μ=1.81e-5; γ=0.072; g=9.81 (axis 1); P_atm=101325. EOS: u_ref=√(2g·col_h)≈1.4 m/s, c_s=max(10u_ref,5)≈14 m/s → K_l=ρc_s²≈1.96e5, K_g≈240. **Artificial viscosity alpha_art=2.0** (SPH-style μ_art=α·ρ·c_s·dx, per Hydrostatic_column precedent). t_ref=√(col_h/g)≈0.1 s; **t_end=0.02 s (~0.2 t_ref) deliberately short smoke test**; cfl=0.1; n_refine 2D=3, 3D=2. dt = `cfl_timestep` (0.1·dx_min/c_s) ⇒ n_steps ~O(200–400) → fast.
- **Success**: qualitative (column collapses, KE_liq history, phase plot); no in-script quantitative Martin–Moyce front-position comparison. Integrator wrapped in try/except so partial snapshots survive divergence.
- **Stability note (verbatim, README)**: "The current DDG FVM stress operator develops large spurious accelerations at free-surface and multiphase-interface corner vertices where the barycentric dual cell is truncated." Mitigations: alpha_art=2.0, short t_end, cfl=0.1, **`skip_triangulation=True`** ("full Delaunay retopologisation every step creates cross-phase edges that destabilise the interface"), boundary_filter, try/except. "For longer / higher-fidelity runs the case needs the interface curvature and dual-split improvements listed under Planned in FEATURES.md."
- **Outputs**: `fig/dam_break_2D{,_no_air}.mp4`, `*_fluid.png`, `*_phases.png`, `*_energy.png`; `results/snapshots_2D{,_no_air}/`, `snapshots_3D{,_no_air}/`.
